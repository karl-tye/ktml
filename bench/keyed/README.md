# Keyed Repetition benchmark

A separate module so templ (`v0.3.1020`) is never a dependency of the main
KTML module. `list/list_ktml.go` and `list/list_ktmlschema.go` are generated
by `gogen` and kept current by
`go test ./internal/generator/gogen -run KeyedBenchmark` (add `-update` to
rewrite them); `list/list_templ.go` is generated by `templ generate`.

```sh
go test ./...                                   # byte-identical output check
go test -run '^$' -bench . -benchmem -count=6 -cpu=1 -benchtime=0.5s ./list
```

Results and the gate verdict: [docs/language/keyed-repetition-benchmark.md](../../docs/language/keyed-repetition-benchmark.md).
